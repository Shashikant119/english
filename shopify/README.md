# Shopify Liquid Basics

This folder is a beginner-friendly introduction to Shopify Liquid and section
schema.

## Files

- `tutorial.md` — step-by-step explanation of Liquid, commonly used filters,
  and section schema.
- `basic-section.liquid` — a complete section that you can add to a Shopify
  theme and customize in the Theme Editor.

## Quick start

1. Open Shopify Admin.
2. Go to **Online Store → Themes**.
3. On a development or duplicate theme, click **... → Edit code**.
4. Open the `sections` directory.
5. Click **Add a new section**.
6. Name it `basic-section`.
7. Copy the contents of `basic-section.liquid` into the new file and save it.
8. Open **Customize**, add the **Basic learning section**, and change its
   settings.

Always test code in a duplicate or development theme before changing a live
store.
