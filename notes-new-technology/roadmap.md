# Six-Month MERN Roadmap

Assumption: 2–3 hours daily, six days each week. Spend roughly 40% learning, 50%
building, and 10% revision.

## Month 1 — JavaScript

Weeks 1–4: syntax/types; functions/scope; objects/arrays/modules; async/DOM/storage.
Build expense calculator and product browser. Solve 40 small problems.

## Month 2 — React

Weeks 5–8: components/state/forms; hooks/effects; router/API/auth UI; architecture,
testing, performance, deployment. Build the React expense manager.

## Month 3 — Node, Express, MongoDB

Weeks 9–12: Node/runtime; Express/REST/errors; Mongo schema/query/indexes; integrated
CRUD and tests. Build student manager and document the API.

## Month 4 — Authentication and production CRUD

Weeks 13–16: password/session/JWT; refresh/RBAC/ownership; uploads/email/jobs;
security/testing. Build task manager or Blog CMS.

## Month 5 — Advanced product

Weeks 17–20: dashboard/aggregation; cache/queue/realtime; e-commerce workflows;
payment sandbox/webhooks. Build an advanced project.

## Month 6 — Deployment and interviews

Weeks 21–24: Docker/CI; cloud/Atlas/TLS; observability/load/security review;
portfolio polishing, system design, mock interviews, applications.

## Daily plan

```text
15 min retrieval practice
35 min concept and handwritten notes
70 min coding without copying
20 min tests/debugging
10 min learning log and next task
```

## Weekly goals

Monday–Thursday learn/build; Friday integrate and test; Saturday ship, review, and
write documentation; Sunday rest or light spaced repetition. Every fourth week,
reduce new material and repair weak foundations.

## Revision schedule

Review a concept the same day, next day, after 3 days, 7 days, 14 days, and 30
days. Rebuild one feature from memory weekly. Maintain an error journal containing
symptom, root cause, fix, prevention, and test.

## Job-ready exit criteria

- Explain complete browser-to-database request flow.
- Build and deploy secure CRUD without tutorial copying.
- Write tests and diagnose network/server/database failures.
- Show two polished projects, one advanced project, architecture documents, and
  meaningful Git history.
- Complete mock coding, JavaScript, React, backend, database, system design, and HR interviews.
